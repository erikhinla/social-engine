# Skill: weekly retro

1. Run `python3 scripts/retro.py <week>`. It ranks the week's posts by PROOF starts per 1,000 views and compares each test the brief named.
2. Write at most two rows for `_context/learnings.md`: what we saw, what we'll do differently. One sentence each.
3. If a learning changes a rule (a hook, a format, a time), follow `protocols/change-protocol.md` so the Keystone file changes too.
4. Next week's brief starts by quoting the kept rows.
