# Skill: write a post

1. Read `_context/AI-CONTEXT.md` and follow its reading order.
2. Read this week's brief in `01_briefs/`. Write only for the idea and hook it names.
3. Read `_context/channels.md` for the channel's job, format and link rule.
4. Write one file per post in `02_drafts/<week>/<id>-<channel>.md` using `templates/post.md`. Fill every front-matter field.
5. Open with the scene. Say the turn in one line. End with the CTA from `mandatories.md` for that channel.
6. If the post needs a picture, name it in `asset:`. If it's new, describe it in `visual:` and use `skills/make-a-still.md`.
7. Run `python3 scripts/check_post.py <file>`. Fix every FAIL. Leave WARN only if you can say why in `notes:`.
